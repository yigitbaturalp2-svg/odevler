## 💻 Mac (macOS) Üzerinde Çalıştırma

Projeyi macOS bilgisayarınıza klonlamak ve çalıştırmak için:

```bash
# 1. Depoyu klonlayın
git clone https://github.com/yigitbaturalp2-svg/odevler.git

# 2. 1. Ödev klasörüne geçin
cd odevler/odev-1

# 3. Bağımlılıkları yükleyin
flutter pub get

# 4. Testleri çalıştırın
flutter test

# 5. macOS veya iOS Simülatöründe başlatın
flutter run
```
